# 采用确定性异动扫描前置门禁与日内快慢双模认知机制

禁止按固定分钟频率对全市场标的轮询调用大模型，也禁止在日内链路中采用多智能体自由多轮辩论群聊。在认知层之前设立纯数值确定性 `Scanner` 作为唤醒门禁，仅当候选标的满足流动性与结构异动条件时才冻结快照唤醒 DeepSeek Harness；同时在认知接口上统一支持两种互补输出模式：**战术洞察模式**（输出单笔 `Setup Insight` 交由四重屏障 `Position Executor` 毫秒级自治托管）与 **参数调优模式**（输出有界 `Controller Patch` 周期性校准本地毫秒级纯代码控制器）。

## Considered Options

- **定时全量轮询大模型并由模型在后续轮次决定何时平仓**：实盘基准（如 Alpha Arena 复盘）已证明该模式在日内波动中会导致高昂 Token 成本、频繁无效换手失血，以及暴跌时因跨轮次推理延迟导致止损滞后穿仓。
- **默认堆叠牛熊辩论、多风格风险讨论员等十余个拟人化角色**：每增加一轮串行对话都会线性拉长日内 `Decision Latency (Δt)`，且缺乏证据表明多轮自由聊天在日内时间尺度上优于单次层级合成加编程式工具验算（PTC）。是否拆分子代理必须以评测模块的净成本消融增益为前提。

## Consequences

- 日内建仓后的毫秒级盯盘、硬止损、止盈、移动保本与持仓超时退出完全由 Python 执行层内的 `Position Executor` 独立闭环完成，即使大模型服务超时或中断也不会导致持仓失去保护。
- 5m/15m 以上事件与结构波段机会走 `Setup Insight`，1m/5m 以下高频微结构逻辑走确定性控制器配合慢层 `Controller Patch`，两者共享下游同一套组合风控、模拟撮合与账本归因。
