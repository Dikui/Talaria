# 09 — 清单连续换代时保全 SDK 补尾

**What to build:** 服务正常响应时，即使清单在补尾与 SDK 直读之间多次换代，查询仍要有明确的一致性结果。复用现有修订与时点规则。

**Found by:** [05 — 实测：补尾与直读的并发一致性、Arrow IPC 传输耗时](05-measure-tail-consistency-and-arrow.md)。

**Source of truth:** ADR-0016、ADR-0018、`docs/architecture.md` §4.3。

**Status:** ready-for-agent

## 复现

1. 冷库中有 BTC 的柱 A。发出下一根确认柱 B，让它进入热缓冲，延后其冷库任务。常驻服务的健康检查和范围查询可正常响应。
2. 调用 `sdk.bars` 查询 A 到 B。两次 `tail_only` 响应均返回 B。在每次响应已经生成、SDK 尚未读取清单时，向同一冷库发布一根 ETH 柱。这使全局清单代号分别从 1 变成 2、从 2 变成 3。
3. 实际结果为只有 A 的 `BarsResult`，`tail_completed=False`。放行 B 的写入后，直读可得到 A、B。此场景没有写盘异常或连接失败。

`sdk.bars` 只接受与所有补尾分段相同的全局清单代号。两次不匹配后走与离线读取相同的路径，丢弃已收到的热端数据。压力运行也观察到了在线降级时缺少已确认柱。

## 验收

- [ ] 通过公开的 SDK 与范围路由复现上述时序，并验证可用服务下返回 A、B 各一次。若在有限重试内仍无法取得一致视图，给调用方明确的可重试错误。
- [ ] 覆盖补尾目标序列自身的清单更新和跨多个 HTTP 分段的查询，保留 `as_of` 截断与最大可见 `revision` 语义。
- [ ] 服务不可用时仍可读取本地冷库，退役文件缺失时仍按 ADR-0018 重读清单一次。

## Comments

### 实现记录（2026-11-22）

- `/api/bars?tail_only=true` 返回 `X-Talaria-Bars-Manifest`。指纹来自协调热端修订时采用的清单，按读取顺序标识与该段相交的 Parquet 路径与内容哈希。SDK 从一次清单读事务选出整个查询范围的文件，逐段核对指纹后拼接。其他标的推进全局清单，或同一序列在尚未查询的分段中写入，都可以与已匹配的补尾一并返回。
- 任一分段的指纹与直读清单不匹配时整次重试一次。再次不匹配会抛出可重试的 `sdk.BarsConsistencyError`。旧服务没有指纹时继续核对全局代号。服务不可用时返回本地结果，标记 `tail_completed=False`。读到退役文件已缺失时仍按最新清单整次重读一次。
- 沿用现有 `as_of` 截断、最高可见修订和确认柱规则。与 ADR-0016、ADR-0018 及架构 §4.3 未发现冲突。范围内 Parquet 合并换文件时也会重新核对，即使合并保留了全部修订。
- 使用真实范围路由和进程内 HTTP 调度确认柱延后写入、ETH 连续推进全局清单、目标范围持续变动及跨段选版。缺柱和静默返回本地结果分别在修复前各复现一次失败，修复后的受影响测试共 202 项通过，`contract-check` 零漂移。实际回环 TCP 与生产写入负载未实测。
- 逐路径暂存时，沙箱拒绝在主仓库的 worktree 元数据目录创建 `index.lock`，`git add` 返回 128。改动保留在 `ticket/data-access-09` 工作区，HEAD 为 `dbe8ee1`。

### 审查修复

- 补尾响应增加 `X-Talaria-Bars-Hot-Revision`，标识目标序列在读取清单和热缓冲时的版本。读取期间有热端变动时，服务标记该段为 `unstable`。SDK 核对所有分段的热端版本和冷文件指纹，整次重试一次后仍无法确认一致时抛出 `BarsConsistencyError`。旧服务缺少热端版本时，仅单段查询可继续使用原有清单校验。
- 在线查询省略 `as_of` 时，每次尝试取 `/api/health` 响应中的服务时钟，供所有 HTTP 分段和 SDK 冷库选版共用。服务时钟为 `130000` 时，`130001` 才可见的冷库修订会被截断。
- 两项修复均先通过公开 SDK 和 ASGI 范围路由复现失败。新增回归覆盖跨段热端换代后重试成功、重试耗尽、未来冷库修订和分段间时钟变化。受影响测试 94 项通过，`contract-check` 零漂移。指定全量测试 888 项通过，1 项按默认配置过滤。沙箱拒绝绑定回环端口导致 14 项失败、1 项初始化错误，拒绝写入本机 DSH 配置另导致 1 项失败。
