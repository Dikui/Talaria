# 10 — 关键位引擎第一批（结构位 / 时段参考位 / 缺口与整数关口）与 `SYSTEM_LEVEL` 图层

**What to build:** 交易员在看盘页打开只读 `SYSTEM_LEVEL` 图层，看到系统按截止时刻确定性识别的结构位、`Trading Session` 参考位、未回补缺口与整数关口，可按类别与强度过滤，对单条关键位标记“忽略”作为质量反馈。关键位带跨快照稳定的 `level_id`，随闭合 K 线增量更新状态。

**Blocked by:** 04 — 单一实现技术指标算子核与图表主副图指标（强度与容差使用 ATR）

**Source of truth:** [需求文档](../spec.md)、[领域词汇表](../../../GLOSSARY.md)、[系统分层架构规范](../../../docs/architecture.md)、[ADR-0002](../../../docs/adr/0002-capability-traits-and-market-packs.md)、[ADR-0008](../../../docs/adr/0008-analysis-first-v1-and-deterministic-key-level-engine.md)

**Status:** ready-for-agent

- [ ] 无前视纯函数产出：① 结构位（摆动高低点与多次触及聚成的区间；摆动枢轴须经后续确认柱数闭合后才产出，`Available Time` 记为确认柱收盘时刻）；② 时段参考位（前日高 / 低 / 收、周与月开盘价、开盘区间，以及由 `SessionTrait` 提供的加密亚洲 / 伦敦 / 纽约分段高低点，核心引擎不硬编码时区）；③ 未回补跳空缺口与整数关口。借鉴参考项目算法时遵守 01 的许可证结论，洁净室实现。
- [ ] 每个关键位具备稳定 `level_id`、单价或区间、周期、强度评分与构成明细（触及次数、最近触及时刻、成交量权重）、状态（`ACTIVE | BROKEN | FLIPPED`）与算法版本参数；黄金向量覆盖确认延迟无前视与状态转换。引擎接口可扩展新类别（11 加入成交量位与清算估算）。
- [ ] 快通道开放 `get_key_levels`（按周期、类别、强度筛选排序），WebSocket 单向投影 `SYSTEM_LEVEL` 图层，不混入画线表。
- [ ] 看盘页按类别与强度阈值过滤显隐；“忽略”操作持久化到协同与感知状态库。“采纳为人工画线”由 14 实现。
- [ ] 浏览器界面验收（均附截图）：宽度 `1440` 与 `390`、浅色与深色、简体中文下检查过滤面板与关键位图例；覆盖长标签防重叠、高强度过滤下无匹配的空列表提示。`390` 下只读显示。
