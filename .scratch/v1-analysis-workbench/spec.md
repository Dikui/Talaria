# 初版人机共用分析工作台（M1–M2）

Status: resolved
ADR review: done 2026-11-19

## Problem Statement

个人日内与波段交易员在观察加密永续合约等可交易金融合约（`Instrument`）时，面临三类核心痛点：

1. **缺乏无前视偏差的统一数据与重要价位底座**：手工识别多周期结构位、时段参考位与成交量分布耗时易漏；若直接让大模型猜测支撑阻力或接入自行拉取实时行情的外部工具，不仅会产生脱离盘面的幻觉价位，还会绕过时点截断导致人与智能体看到的数据不一致，更无法做历史复现与有效性检验。
2. **多端指标计算漂移与慢速推理阻塞看盘**：前端图表、后台预警与智能体工具若各自独立实现技术与衍生品指标，极易因预热期、空柱或断流处理差异产生数值漂移；而把实时行情与人工画线通道串在大模型宿主上，又会在模型长耗时推理或断连时卡死交易员切图、画线与查看预警。
3. **缺少可控的人机同屏协同分析（`Co-Pilot Analysis`）闭环**：交易员既希望在不启动智能体时轻量独立看盘，也希望在需要时框选盘面局部区间发起会诊、让智能体基于同一份冻结证据快照（`Evidence Snapshot`）与关键位（`Key Level`）给出有据可查的图表标注和异动扫描简报，且严禁定时全量轮询大模型造成高昂推理开销。

## Solution

依据 [ADR-0008](../../docs/adr/0008-analysis-first-v1-and-deterministic-key-level-engine.md) 与[系统分层架构规范](../../docs/architecture.md)，初版聚焦交付跨越里程碑 M1 与 M2 的**人机共用分析工作台**（暂不包含交易定仓、模拟撮合与资金账本闭环）：

1. **时点严密的 `Bybit V5 Linear` 感知底座与单一实现指标核**：以可插拔市场规则包（`Market Pack`）接入免密钥 `Bybit V5 Linear` 永续合约实时与历史行情、标记价格（`Mark Price`）、资金费率结算（`Funding Settlement`）历史与持仓量数据，沉淀冷热一体时点存储并支持按截止时刻冻结不可变 `Evidence Snapshot`。全部技术与衍生品指标仅在 Python 确定性底座实现一份，图表渲染与智能体编程式工具调用（PTC）统一消费同一结果。
2. **确定性 `Key Level` 引擎与零阻塞独立看盘工作台（M1，`--solo`）**：由确定性纯函数仅基于截止时刻前已可见数据产出跨快照稳定身份的五类 `Key Level`（确认后可见的摆动结构位、交易时段 `Trading Session` 参考位、成交量分布与锚定 VWAP、未回补跳空缺口与整数关口、单独标记为估算的清算密集区），并配套随机价位对照的离线反应率评估。提供本地回环快通道直连的纯 React + `KLineChart v10` 看盘工作台，支持自选观察池（`Watchlist`）、主副图指标叠加、`SYSTEM_LEVEL` 只读关键位图层、`HUMAN_DRAWING` 人工画线（`Chart Overlay`）及四类盘面预警（`Alert`），无需启动智能体即可独立流畅运行。
3. **共享分析接口与 DeepSeek Harness 双轨协同分析（M2）**：浏览器与 DeepSeek Harness 智能体共用同一套绑定 `snapshot_id` 的本地分析接口。接入协同工作台宿主后，支持交易员框选图表区间发起会诊、智能体经 PTC 调取同口径算子解读盘面、经价格包络与证据引用硬门控校验后写入 `AGENT_ANNOTATION` 图表建议标注、提交待人工确认的 `Alert` 草案，以及由确定性异动扫描前置门禁触发唤醒事件（`Trigger`）生成后台扫描简报；数据陈旧、逻辑冲突或模型超时一律降级为显式弃权（`Abstain`），人工快通道全程零阻塞。

## User Stories

1. As an 独立日内交易员, I want to 通过免密钥渠道拉取并持续同步 `Bybit V5 Linear` 永续 `Instrument` 的多周期 K 线、最优买卖盘口、`Mark Price`、`Funding Settlement` 历史与持仓量并按指定截止时刻冻结 `Evidence Snapshot`, so that 实时看盘与历史时点复现建立在同一份无前视泄漏的数据事实上。
2. As an 独立日内交易员, I want to 在不启动大模型宿主的情况下单命令启动本地独立看盘工作台（`--solo`）管理 `Watchlist`、切换 `Instrument` 与周期、查看实时行情和衍生品状态，并在数据源断流时收到明确陈旧状态提示, so that 日常高频看盘轻量可靠且零大模型等待。
3. As an 独立日内交易员, I want to 在图表主副图叠加与切换由 Python 底座统一计算的技术与衍生品指标（且在异常断流后自动执行完整重预热而非输出失真值）, so that 图表展示、盘面预警与后续智能体工具读到的指标数值严格一致。
4. As an 独立日内交易员, I want to 在图表上使用交互工具自由绘制、拖拽编辑（拖拽过程不等待后端写入）、撤销重做并按周期管理 `HUMAN_DRAWING` 类型的 `Chart Overlay`, so that 我的主观结构判断能无延迟地持久化保存并供后续预警和协同会诊读取。
5. As an 独立日内交易员, I want to 在只读 `SYSTEM_LEVEL` 图层查看系统按截止时刻确定性识别的结构位、`Trading Session` 参考位、成交量位、缺口/整数关口及单独标识的估算清算密集区，按类别与强度过滤，并将认可的 `Key Level` 一键采纳为人工画线或标记忽略, so that 我能快速获得可复现的重要价位参考并沉淀人工反馈数据。
6. As an 量化研究与系统维护者, I want to 对各类型 `Key Level` 运行离线质量评估（统计触及后指定 ATR 倍数内的价格反应比例并与随机价位对照）, so that 关键位识别算法与强度权重具备客观统计依据而非主观臆断。
7. As an 独立日内交易员, I want to 基于价格/衍生品阈值、指标信号、`HUMAN_DRAWING` 画线突破以及系统 `Key Level` 触及/突破/回踩创建 `Alert`（含图上一键挂载），并在触发时毫秒级收到工作台桌面弹窗与高亮声音提醒, so that 我无需盯紧全部 `Watchlist` 标的也能及时捕获关键盘面变化。
8. As an 人机协同交易员, I want to 在同屏工作台中框选图表局部时间-价格区间或针对当前 `Instrument` 发起 `Co-Pilot Analysis` 会诊，让智能体基于同一冻结 `Evidence Snapshot`、`Key Level`、可见 `HUMAN_DRAWING` 与 `Catalyst Calendar` 时点窗口调用 Python 同口径算子输出结构化战术交易洞察（`Setup Insight`，只读参考）或在异常时返回 `Abstain`, so that 智能体能与我对齐完全相同的盘面截面做无心算误差的辅助推演，同时绝不阻塞本地看盘操作。
9. As an 人机协同交易员, I want to 审阅智能体写入 `AGENT_ANNOTATION` 图层的建议标注（自动拦截无证据引用或超出近期 ATR 合理包络的幻觉价位）以及智能体提议的 `Alert` 草案，并支持一键采纳标注为人工实线、按会话过滤清理或确认激活预警, so that 智能体的盘面辅助直观可控且不会污染我的主图画布。
10. As an 人机协同交易员, I want to 由后台确定性异动扫描器对 `Watchlist` 执行结构与衍生品异动门禁过滤，仅在满足条件且通过冷却与并发限流时生成 `Trigger` 与后台扫描简报卡片，支持一键跳转对应 `Evidence Snapshot` 图表继续会诊, so that 我能在控制模型 Token 成本的前提下兼顾多标的异动感知。

## Implementation Decisions

- **双平面职责边界与严格单向分层**：遵循 [ADR-0001](../../docs/adr/0001-dual-plane-dsh-and-python-core.md) 与架构规范，初版涉及公共底座契约层（`L0`）、数据与盘面感知层（`L1`）、策略层只读洞察与智能体工具绑定（`L2` 只读子集）以及外圈人机协同工作台交互层（`O2`）。核心业务层仅依赖 `L0` 契约，禁止反向导入外圈模块。
- **跨语言单一契约源与数值/时点纪律**：所有价格、数量、费率在 Python 内部强制使用定点十进制，跨 JSON 边界统一序列化为十进制字符串（仅前端 Canvas 像素绘制最后一跳转为浮点数）。所有行情与事件记录显式携带五重时点（`Event Time`、`ts_published`、`Available Time` + 精度等级、`ts_ingested`、`Committed Time`）。由 Python 模型自动导出跨语言 JSON Schema 与前端类型，同时输出剥离根级 `$schema` 并展开 `$defs` 的工具定义以符合 DeepSeek Harness 校验子集。
- **市场规则包（`Market Pack`）可插拔隔离**：遵循 [ADR-0002](../../docs/adr/0002-capability-traits-and-market-packs.md)，`L0/L1/O2` 核心逻辑只面向通用 `Instrument` 与五项能力特征接口编程，禁止编写特定资产类别条件分支；初版首发注册加密永续规则包中的 `Bybit V5 Linear` 免密钥连接器、`24x7` 连续 `Trading Session`（含加密亚洲/伦敦/纽约分段参考窗口）及衍生品特征，`Catalyst Calendar` 在 `L1` 预留双时间防前视查询裁剪语义（未到可获取时刻隐藏实际结果）；初版只提供空实现接口，不接入任何日历数据源。
- **冷热一体时点存储与热端冻结物化**：冷库采用单写者“原始报文哈希归档 → 临时质检 → 不可变列式批次原子落盘 → 清单库短事务提交”流程；实时热流区分闭合状态与数据修订（`Revision`），区分正常窗口内稀疏无成交与真实传输断流。每次因会诊或 `Trigger` 调用快照冻结时，实时热流未归档切片即时物化落盘，列式查询引擎仅读取快照清单显式列出的文件集合。初版只实现 `HISTORICAL_PIT` 查询；`OBSERVED_REPLAY` 服务于 M3 回放，初版仅如实记录 `Committed Time` 并在查询接口预留模式参数（传入时返回明确的未实现错误）。
- **单一实现确定性算子核**：遵循 [ADR-0008](../../docs/adr/0008-analysis-first-v1-and-deterministic-key-level-engine.md)，技术与衍生品指标（趋势均线、震荡、波动率、成交量加权均价、资金费率分位数、持仓量背离度、净赔率几何验算）仅在 Python `L0` 基于剔除正常休市空槽的紧凑交易柱序列实现一份（底层结合批量库与增量流式库）：输入输出严格等长、预热期输出前导空值、无成交柱按前收盘平盘零量保态递推、遭遇真实传输断流立即输出空值并强制重跑完整预热期。图表通过自定义指标渲染接口直接绘制后端返回序列，智能体通过 PTC 远程调用同一算子。
- **确定性 `Key Level` 引擎与防前视确认延迟**：五类 `Key Level` 均由无前视纯函数按截止时刻计算，摆动高低点必须经过后续确认柱数闭合确认后才可产出，其 `Available Time` 严格记为确认柱收盘时刻；清算密集区显式标记为估算类别并与观测类价位分开展示，排在关键位实现的最后一批；跨快照保持稳定 `level_id`，随闭合 K 线增量更新有效状态（活跃、跌破/突破失效、支撑阻力互换）。
- **单写者本地分库与快通道安全基线**：遵循 [ADR-0005](../../docs/adr/0005-fast-path-bypass-and-decoupled-chart-workbench.md) 与 [ADR-0006](../../docs/adr/0006-single-position-round-per-subaccount-and-isolated-ledgers.md)，初版启用冷库清单库、实时物化快照库、协同与感知状态库三个独立单写者 SQLite 库（开启 WAL 模式，协同状态库由守护进程内单一异步串行队列独占写入）。守护进程仅监听 `127.0.0.1` 回环地址，所有写操作接口强制校验进程启动时随机生成的会话 Bearer Token。
- **人机共享图表三活动图层与共用分析接口**：初版在无框架耦合的纯 React 看盘组件包（基于 `KLineChart v10` 核心库，不引入 SolidJS 版外围封装）中落地三个独立图层：`HUMAN_DRAWING`（交易员手绘与拖拽）、`SYSTEM_LEVEL`（系统关键位只读投影与一键采纳/忽略反馈）、`AGENT_ANNOTATION`（智能体建议标注）。浏览器与智能体共享同一套七项分析接口（冻结快照、读取指标、读取关键位、临时算子计算、读取当前视窗与可见人工画线、受控写入智能体标注、创建预警草案）。
- **智能体标注防幻觉硬门控与协同宿主权限物理隔离**：遵循 [ADR-0001](../../docs/adr/0001-dual-plane-dsh-and-python-core.md) 与 [ADR-0004](../../docs/adr/0004-dual-mode-intraday-cognition-and-scanner-gate.md)，智能体写入 `AGENT_ANNOTATION` 前必须通过 Python 确定性校验（快照存在且匹配 `Instrument`、非空证据引用指向有效 `level_id` 或具体 K 线时刻、价格为正且对齐最小变动价位并落在分析窗口极值外扩 3 倍 `ATR_14` 包络内、向未来推演跨度不超过 100 根 K 线、单标的未采纳活跃标注不超过 12 条）；智能体创建的 `Alert` 默认处于草案态，须经人工确认后方可激活。协同 Profile 在配置补丁层物理移除任何自动下单工具并挂载单调执行守卫（拦截历史轨迹分支重放），同时在宿主侧于每轮对话结束时幂等采集会话与轮次级 Token 用量留痕，供后续账本闭环直接复用。后台异动扫描器严禁定时全市场轮询大模型，仅在数值门禁命中且通过冷却锁与全局并发令牌桶时生成协同简报。

## Testing Decisions

- **好测试的定义**：测试只验证模块公开边界上的可观测外部行为、时点因果不变量与错误契约（给定输入行情/快照/请求，断言输出数据、状态流转、持久化查询结果或明确拒绝码），不绑定内部私有函数拆分、内存缓存结构或 SQL 表内部实现细节。
- **选定的高层测试边界**：
  1. **人机共用分析快通道与感知输入缝隙边界（主集成测试边界）**：在数据源连接器与统一市场事件流（`MarketEventFeed`）入口注入确定性的 `Bybit V5 Linear` 历史与实时样本流，统一通过 `workbench_api` 的 HTTP/WebSocket 公开接口与受控桥接契约验证：快照冻结与热端物化恢复、时点截断防前视、紧凑序列指标与断流重预热、`Key Level` 跨快照稳定性与离线评估、`HUMAN_DRAWING` 与 `Watchlist` 持久化、`Alert` 与异动扫描状态机路由，以及 `AGENT_ANNOTATION` 越界/无证据硬门控拦截与 `Abstain` 降级。
  2. **跨语言契约与黄金测试向量边界**：验证 Python 导出的 JSON Schema 与前端类型零漂移、金额/价格十进制字符串约束、DeepSeek Harness 工具 Schema 子集静态合规、`dsh --dump-config` Profile 权限快照，以及算子与 `Key Level`（含确认延迟无前视与断流重预热）黄金向量回归。
  3. **真实浏览器端到端界面验证**：在 `--solo` 单进程与双平面协同模式下，通过真实浏览器验证桌面端（宽度 `1440`，全部交互）与窄屏端（宽度 `390`，只读浏览：看 K 线、指标、关键位、预警与简报，画线编辑和框选会诊等编辑类控件隐藏或禁用）、浅色与深色主题、简体中文界面与长标的/长文案排版，以及空自选/无关键位/数据源断流/智能体宿主离线等空态与降级态。
- **代码库中的测试先例**：当前仓库尚处于架构定稿后的零业务代码起步阶段，测试组织与运行约定以 `AGENTS.md`、`docs/agents/layout.md`（按模块组织的单元/性质测试与按功能组织的场景回归测试，开发中仅按 `/local-test` 运行受影响的 `pytest` 用例）及架构规范 §5.3 的自动化契约门禁为准。需访问外部真实网络的在线公共行情或真实模型会话检查单独归入可选冒烟验证，不阻塞离线确定性测试套件。

## Out of Scope

- **里程碑 M3 交易闭环模块**：虚拟子账户（`Sub-Account`）风险单元（`Risk Unit`）定仓与七步硬风控流水线（`L3`）、暂存交易草案（`Staged Plan Draft`）下单审批与 `EXECUTION_BARRIER` 执行屏障图层、仓位生命周期执行器（`Position Executor`）与模拟撮合器（`L4`）、权威复式资金账本（`Ledger`）、`Co-Pilot Lift` 反事实评测、`Trade Journal` 复盘面板（`L5`）及历史批量回放器。
- **里程碑 M4 智能体自治、参数寻优与美股市场包**：`talaria-auto / talaria-eval` 子进程自治与基于模型知识截止日的评估证据等级（`Evaluation Evidence Tier`）回放评测流水线、外圈 `Optuna` 防过拟合参数寻优器，以及美股市场规则包（Alpaca IEX/SIP、Finnhub、SEC EDGAR、BLS/BEA/FOMC/ALFRED 连接器与 Reg-T / PDT 规则）。
- **初版暂缓的感知能力**：`OBSERVED_REPLAY` 查询实现（随 M3 回放器交付）、`Catalyst Calendar` 数据源接入、窄屏端（`390`）的画线编辑与框选会诊。
- **实盘柜台对接、高频做市与多租户服务**：真实交易所/券商资金下单与外部柜台对账、微秒/毫秒级订单簿做市或跨所套利、多用户账号权限与商业化 SaaS 托管。
