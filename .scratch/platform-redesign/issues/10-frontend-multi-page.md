# 10 — 前端多页面：每个功能一个可直接打开的路由

**What to build:** 图表、预警、扫描、关键位各有一个可直接打开的页面，可以开在多个标签页或窗口，也能装成 PWA 独立窗口；在一个页面切换标的或周期，其他已打开页面跟着联动（`BroadcastChannel`）。每个页面只打开它自己时也能完整工作。

**Blocked by:** None — can start immediately.

**Source of truth:** ADR-0014；`docs/architecture.md` §1.1。

**Status:** ready-for-agent

- [ ] 路由：图表、预警、扫描、关键位；原单页工作台入口保留并链接到各页面。DSH 插槽中的工作台不受影响。
- [ ] 提供 Web App Manifest，可在浏览器中安装为独立窗口。
- [ ] 联动：同一浏览器内两个页面切换标的/周期互相同步，十字光标时刻同步；关闭任一页面不影响其他页面。
- [ ] 浏览器检查并截图：宽度 1440 与 390、浅色与深色主题；空数据（无自选、无预警）与长标的名称；两个窗口联动的前后截图。
