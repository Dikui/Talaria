# 12 — JSON 规则与预警升级

**What to build:** 预警条件可以写成组合规则（如“收盘上穿 EMA20 且 RSI < 70 且资金费率为负”），以带版本号的 JSON 表达式树保存，在服务内求值；已有的单条件预警自动迁移为等价规则，触发行为不变。

**Blocked by:** 11 — 组件接口、运行时上下文与 Python 写法。

**Source of truth:** ADR-0019；`docs/architecture.md` §5.2、§5.3。

**Status:** ready-for-agent

- [ ] JSON 规则 Schema（带版本号），只能引用已注册算子；导出 JSON Schema 与 TypeScript 类型。
- [ ] 规则编译到组件接口，在服务内和账户进程内用同一求值器。
- [ ] 现有 `AlertCondition` 迁移为规则；旧形式在迁移后移除，搜索旧条件类型无残留；预警冷却、画线触碰、关键位事件行为保持。
- [ ] 扫描可以使用同一规则形式。
- [ ] 测试：迁移前后对同一回放的触发记录一致；非法规则（未注册算子、版本不兼容）被拒绝。
