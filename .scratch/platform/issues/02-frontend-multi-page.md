# 02 — 功能面板进 DSH，兜底页面复用同一批组件

**What to build:** 图表、预警、扫描、关键位各做成一个独立的功能组件。在 DSH Web 里，每个组件注册为一个全局面板（root 作用域 `main` keyed slot，`ctx.layout.selectPanel(id)` 切换），交易员从 DSH 侧栏或命令进入。同一批组件也挂在服务托管的独立路由上，作为 DSH 离线时的兜底入口。在任一面板切换标的或周期，其他已打开的面板（DSH 内、其他 DSH 标签页、兜底页面）都跟着联动（`BroadcastChannel`）。

**Blocked by:** None — can start immediately.

**Source of truth:** ADR-0020（取代 ADR-0014 的前端一条）、ADR-0005；`docs/architecture.md` §1.1。

**Status:** ready-for-agent

**2026-11-22 改写：** 原单是“浏览器多页面 + PWA”为主、DSH 插槽为另一使用方；按 ADR-0020 改为 DSH 为主入口。

## 原型结论（2026-11-21 原型，2026-11-22 定方案）

原型比较了三种组织方式，都复用真实的功能组件和 API：A 独立页 + 全部联动；B 图表主窗 + 面板坞，面板可弹出成小窗、关掉回坞；C 启动台 + 颜色联动组。换到 DSH 后定为 **B 的布局 + C 的联动**：

- **布局**：图表占 DSH 主区。预警、扫描、关键位既能单独占主区，也能作为 DSH 右栏的 tab 停在图表旁边（右栏自带分栏和浮窗，充当原型 B 的“坞”和“弹出”）。不做原型 C 的启动台，入口用 DSH 侧栏。
- **联动**：按颜色分组。每个面板或窗口选红、蓝、绿组或“不联动”，只有同组才同步，这样能同时看多个标的。新开的面板默认红组。

原型已验证、照搬到正式实现的联动机制：

- 一个 `BroadcastChannel`，消息有：`symbol`（标的 + 周期）、`crosshair`（时刻）、`locate`（标的 + 周期 + 触发时刻）、`ask`（加入组时向组内要当前标的，新开的面板跟上已打开的）、`presence` 心跳与 `bye`。收到消息先比组，不同组忽略。
- 每组的当前标的和周期记在浏览器本地，刷新或换组后恢复。
- 预警或扫描里点“定位”，同组图表切到对应标的和周期，并跳到触发时刻。
- 窗口列表靠 `presence` 心跳（原型 1.5 秒一次、4 秒过期），关掉的窗口自动消失。

原型没覆盖、这张单要补的：

- 十字光标同步：原型只在对方图表画一条虚线，正式实现要驱动对方图表的十字光标。
- 390 宽度。
- 原型控制台出现过一次 401（会话 token cookie 尚未写入就发了请求），没再复现；正式实现要保证取到 token 后再发第一批请求。

原型代码只在本地（`talaria-desk-ui/src/prototype/`、`prototype.html`、`vite.prototype.config.ts`，已列入 `.git/info/exclude`），本单完成后删除。

- [ ] 组件边界：`talaria-desk-ui` 中每个功能组件只从 props 和自己的 hooks 取状态，不 import 任何 DSH 包；DSH 胶水只在 `talaria-dsh-plugin/client`。加一条静态检查（如 import 边界测试）保证这一点。
- [ ] DSH 面板：图表、预警、扫描、关键位四个面板注册到 `main` 插槽，可从 DSH 侧栏进入；会话右栏里现有的图表 tab 不受影响。面板内的行情、历史分页、画线、预警写操作直连服务快通道，不经 DSH 宿主转发（看网络请求确认）。
- [ ] 兜底页面：服务托管四个独立路由，原 `/desk` 入口保留并链接到各页面；只打开其中一个时也能完整工作。不做 Web App Manifest。
- [ ] 状态恢复：DSH 刷新后布局会重置，Talaria 自己在浏览器本地记住当前面板、标的和周期，刷新后恢复。
- [ ] 右栏停靠：预警、扫描、关键位可作为 DSH 右栏 tab 停在图表旁，也可占主区；会诊右栏里现有的图表 tab 照常可用。
- [ ] 颜色联动组：每个面板可选红/蓝/绿/不联动，标题处显示组色。同组的面板之间（DSH 内、两个 DSH 标签页之间、DSH 与兜底页面之间）切换标的/周期互相同步，十字光标同步到对方图表的十字光标；不同组互不影响；新加入的面板跟上组内当前标的；关闭任一方不影响其他。
- [ ] 定位：在预警或扫描里点“定位”，同组图表切到对应标的和周期并跳到触发时刻。
- [ ] 降级：停掉 DSH 宿主后，兜底页面照常看盘、画线、管理预警。
- [ ] 浏览器检查并截图：DSH 面板与兜底页面各一组，宽度 1440 与 390、浅色与深色主题；空数据（无自选、无预警）与长标的名称；两个不同组的图表看不同标的、同组联动的前后截图。
- [ ] 删除本地原型文件及 `.git/info/exclude` 里对应的条目。
